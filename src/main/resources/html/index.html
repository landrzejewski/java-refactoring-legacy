Katalog zawiera materiały pomocnicze do prowadzenia zajęć, podzielone na trzy rodzaje:

Katalog Dla kogo Zawartość
zadania/ uczestnicy (do rozdania) krótkie aktywności, ćwiczenia i warsztaty: cel, czas, dane wejściowe, polecenia, kryteria akceptacji, pytania sprawdzające - bez odpowiedzi

Uruchamianie przykładów

Kod przykładów jest dostępny w trzech językach o tej samej strukturze modułów.

Java (główny projekt, Java 25, Maven)

mvn -q compile
java -cp target/classes pl.training.module1.Module1Examples   # dowolny moduł: moduleN.ModuleNExamples
mvn test                                                      # wszystkie testy
mvn test -Dtest='pl.training.module4.**'                      # testy jednego modułu

Kod: src/main/java/pl/training/moduleN, testy: src/test/java/pl/training/moduleN.

C# (.NET 10)

cd csharp
dotnet build
dotnet test
dotnet run --project src/Training.Module1

TypeScript (Node.js 22+)

cd typescript
npm ci
npm run build
npm test
npm run module1

Sugerowany przebieg modułu

  1. Teoria na podstawie slajdów (slides/).
  2. Demonstracja przykładów z kodu według przyklady/ (najpierw wersja wyjściowa i test charakterystyki, potem kolejne kroki).
  3. Rozdanie zadania/ i praca w parach lub małych grupach.
  4. Omówienie według rozwiazania/, z porównaniem prac uczestników z kodem referencyjnym.
  5. Pytania sprawdzające i lista kontrolna na zakończenie.
